我的第一个 GitHub 仓库，用于学习 Git 与 GitHub 的基本流程。

## 已经掌握的内容

- Git 是本地版本控制工具，GitHub 是代码托管网站
- 通过 SSH 密钥完成身份验证
- 使用 `git init`、`git add`、`git commit`、`git push` 完成首次推送

## 常用命令

```bash
git status          # 查看当前改动
git add .           # 暂存所有改动
git commit -m "说明" # 提交
git push            # 推送到 GitHub
```
